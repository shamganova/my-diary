# My Notes

A free personal diary for iPad: notebooks with covers, Apple Pencil writing, stickers, photos and page templates.
It is a web app: open it in Safari and add it to the Home Screen, and it works like a normal app, even offline.

## Features

- Notebooks with different covers, plus ready-made notebooks
- Writing with Apple Pencil: pen, nib, pencil, marker, highlighter (size, opacity, stabilization)
- Typed text with fonts, sizes, bold, italic, underline and strikethrough
- Page rulings (lines, grid, dots, blank), page colour and line colour
- Page templates: to-do list, day and week planners, lecture, Cornell notes, class timetable, deadlines and exams,
  habit tracker, mood tracker, gratitude page
- 14 picture sticker packs (243 stickers: watercolor, cats, pigeons, food, flowers, space, school and more),
  emoji packs, your own stickers, and photos with an optional polaroid frame
- Lasso: select writing, drawings, stickers and photos, then move, copy, cut, delete or paste them
- Neat shapes: hold the pen still at the end of a line, and it becomes a straight line, circle, rectangle or triangle
- PDF: add lecture slides or any PDF and write on top of them
- Page titles and search (titles, typed text and the text inside PDF pages)
- Share a page or a whole notebook as a PDF, or a page as a picture
- Glitter colours for the pen
- Undo and redo for writing, stickers, photos and text
- A calendar of the days you wrote, and page thumbnails
- A 4-digit lock and a backup file you can save to Files

## Privacy

Everything you write stays on your iPad (in the browser's storage). Nothing is sent to the internet.

## About this project

Idea, design, the app icon (drawn by hand), templates and testing: Anel.
The picture sticker packs were made by Anel with an AI image tool.
The code was written together with an AI assistant (Claude).

Built with HTML, CSS and JavaScript, without frameworks. Free libraries used (loaded from cdnjs when needed):
[PDF.js](https://mozilla.github.io/pdf.js/) to read PDF files and [html2canvas](https://html2canvas.hertzen.com/)
to turn pages into pictures for sharing. Icons: [Tabler Icons](https://tabler.io/icons). Fonts: Caveat and Comfortaa
(Google Fonts).
